# 墨

墨是用烟灰和胶调成的。烧松木得到的烟叫松烟，烧桐油等油料得到的烟叫油烟，再加上动物胶捶打成锭，阴干之后就是一块墨。用的时候在砚台上加水慢慢研开。

## 两种墨

| 种类 | 烟料 | 墨色 |
|:--|:--|:--|
| 松烟墨 | 松木 | 黑，几乎不反光 |
| 油烟墨 | 桐油等油料 | 黑，带一层光泽 |

> [!TIP]
> 研墨时用清水，少量多次，顺着一个方向打圈。

## 研一池墨

- [x] 砚台洗净
- [x] 加几滴清水
- [ ] 研到墨汁挂在砚边不散

墨汁的浓淡大致看墨和水的比例 $c = m_\text{墨} / V_\text{水}$，水越少，墨越浓。

```python
def 研墨(水量, 圈数=300):
    浓度 = 0
    for _ in range(圈数):
        浓度 += 1 / 水量
    return min(浓度, 1)
```
